# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The AgriPulse project takes data privacy and edge security seriously, especially given the socio-economic sensitivity of smallholder farmer telemetric records and commodity market bargaining data.

If you discover a security vulnerability or algorithmic integrity flaw within AgriPulse:
1. Please do **not** open a public issue.
2. Email the maintainers directly with a description of the issue and steps to reproduce.
3. We will respond within 48 hours to coordinate a responsible patch and release.
